1. Объявление переменных
	Перем - команда для обозначения глобальной переменной
	к глобальной переменной можно обращаться из любого обработчика
	название переменной не должно начинаться с цифры (1Перем) и совпадать с командой 1С(Перем), но может начинаться с _
	(мПерем, _Перем, _________П123)
	Тип переменной присваивается в момент присваивания значения переменной (Перем = "строка"; - строчный || Перем = 123; - числовой и т.д.)
	Глобальные переменные называются с префиксом м (мПерем)
	Локальные переменные называются без префикса (Перем)
2. Тело модуля
	Сообщить - команда вывода сообщения в строке
	Сообщить ("Привет, Мир!");
	Перем - если команда используется в теле модуля, то обозначает локальную переменную
	название локальной переменной может совпадать с название глобальной переменной, при этом в теле будет использоваться именно локальная переменная
	
3. Инциализация переменных
	Гл_Перем = 0;

Условный оператор
Сравнение значений делается через >, <, =
При сравнении двух значений в коде он выдаёт "Истина" либо "Ложь"

Реквизиты
При создании реквизитов необходимо указывать тип данных
Для размещения реквизитов на форме необходимо воспользоваться элементом управления "Поле ввода" (внизу экрана)
Если имя поля ввода = имени реквизита, поле автоматически подхватывает значение реквизита
Чтобы обратиться к реквизиту в коде необходимо просто указать название реквизита

ctrl + Space - горячая клавиша в коде для быстрого подставления возможных процедур, значений, переменных и т.д. в текущем месте кода

Массивы
Индексы массивов начинаются с 0
Чтобы обратиться к элементу массива, необходимо обратиться к массиву и указать индекс элемента
М[3] - обращаемся к 4-му элементу массива

Объявление массива:
М = Новый Массив();

Добавление элементов:
М.Добавить(1);
М.Добавить(5);
М.Добавить(15);
М.Добавить(7)

Метод обращения к количеству элементов массива:
К = М.Количество();
